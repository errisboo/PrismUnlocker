PrismUnlocker - программа для удаления трудных вирусов и глубокого аудита

Возможности, которые отличают эту программу от остальных:
Автозагрузки: Персистенция WMI(часто лезут файллессы), LolBins(также частое место файллессов), Dll Hijack & Side-Loading(так же часто лезут профессиональные
вирусы)
Доп.Возможности: показ скрытых дисков(после вычищения вирусов)
Все вредоносные/подозрительные ключи, автозагрузки, файлы, процессы подсвечиваются красным, их количество показано справа сверху
в каждой секции(если они есть)

Программа писалась на C++ DearImGui / WinAPI и не требует никаких библиотек и других файлов
Работает в WinRE/WinPe
